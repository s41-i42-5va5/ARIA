# A.R.I.A. distributions

Download the complete Windows packages from [GitHub Releases](https://github.com/s41-i42-5va5/ARIA/releases/tag/v1.5.5).

The directories below contain release metadata, original documentation and immutable manifests. They are not complete portable distributions and cannot be installed directly. Use the ZIP downloads, which include the framework, runtime, dependencies and installation tools.

Both downloads retain their original manifest and file contents. `SHA256SUMS.txt` checks the published archives.
