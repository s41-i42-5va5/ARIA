# Функциональность ARIA Codex 1.5.5

Фактический контракт поставки построен из wheel
`aria_codex-1.5.5-py3-none-any.whl` и исходного commit
`4f68e97daba6a361b71265610e6e07962476bee0`.

## Сохранённый базовый функционал

- framework/project doctor и локальный реестр проектов;
- specify-to-converge lifecycle и Feature Contract;
- Evidence Package, Ed25519 identity, signed access, backlog и task leases;
- trusted CI, fail-closed gate и release check;
- Codex skill, аудит истории и состояния;
- безопасное обновление проектов предыдущих выпусков 1.5.x.

## Последний P0 backlog

- один GitHub-репозиторий с `main`, `dev`, `work/<github-username>` и
  `aria-control`;
- создание нового проекта, подключение существующего и отдельный
  `aria-control` worktree;
- GitHub-authenticated авторство, invitation/revocation и team lifecycle;
- идеи, owner triage, задачи, зависимости, назначения и file-scope leases;
- локальный Coordinator как единственный писатель control-документов;
- durable GitHub Issue queue, offline outbox и обработка после перезапуска;
- идемпотентность, terminal receipts, pagination и защита от повторного
  применения или подмены request id;
- проверка App receipt по полному запросу, actor, timestamp, revision и
  историческому control commit;
- PR author/source/scope, required checks, merge reachability и accepted-state
  reconciliation;
- crash recovery для clone, control transaction, activity, backlog и окна
  между App-комментарием и закрытием Issue;
- устойчивость к поздним, повторным, отредактированным и пользовательски
  закрытым событиям.

## Граница проверки

Локальный regression и автономная Windows-поставка проверяются в этой сборке.
Живая GitHub-приёмка требует отдельного private-репозитория, GitHub App, аккаунта
владельца и отдельных аккаунтов разработчиков; она не подменяется локальными
mock/integration-тестами.
