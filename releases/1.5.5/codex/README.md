# ARIA Codex 1.5.5 portable test candidate

Эту папку можно целиком скопировать на другой Windows 10/11 x64 ПК. Внешние
Python и Git не требуются. Интернет нужен только для живых операций GitHub.

Быстрый запуск:

1. `CHECK_RELEASE.cmd`
2. `INSTALL.cmd`
3. `RUN_ARIA.cmd doctor`
4. `RUN_ARIA.cmd --help`

Полная инструкция: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Реализованный функционал: [ФУНКЦИОНАЛ.md](ФУНКЦИОНАЛ.md).

Проверки поставки: [ПРОВЕРКА_ПОСТАВКИ.md](ПРОВЕРКА_ПОСТАВКИ.md).

Это полная локально проверенная реализация последнего P0 backlog. Живая
multi-user GitHub-приёмка пока не выполнена и отмечена в manifest как `pending`.
