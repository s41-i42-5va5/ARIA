# ARIA Codex 1.5.5 — переносимая тестовая поставка

## Состав

Передавайте целиком папку `1.5.5 for Codex`. Она содержит:

- полный исполняемый framework ARIA 1.5.5 и wheel;
- Python 3.12.10 и MinGit 2.55.0.5 x64;
- все Python-зависимости для offline-установки;
- установку, запуск, проверку целостности и удаление;
- полный manifest с размерами и SHA-256 всех файлов;
- инструкцию и описание реализованного функционала.

Поддерживается Windows 10/11 x64. Права администратора, установленный Python и
установленный Git не требуются.

## Запуск на другом ПК

1. Скопируйте всю папку `1.5.5 for Codex` на локальный диск нового ПК.
2. Запустите `CHECK_RELEASE.cmd`. В результате должно быть `"ok": true`.
3. Запустите `INSTALL.cmd`.
4. Запустите `RUN_ARIA.cmd doctor`.
5. Для списка команд запустите `RUN_ARIA.cmd --help`.

Установка создаёт внутри поставки:

- `.aria-runtime` — приватные Python, Git, venv и квитанцию установки;
- `.aria-data` — реестр проектов, локальное рабочее состояние и защищённые
  учётные данные ARIA.

## Codex и GitHub

Встроенный Codex skill устанавливается отдельной командой:

```bat
INSTALL.cmd -InstallCodexSkill
```

Вход в GitHub:

```bat
RUN_ARIA.cmd github-auth login-begin
RUN_ARIA.cmd github-auth login-complete
```

Точные параметры операций доступны через `--help`, например:

```bat
RUN_ARIA.cmd project create-plan --help
RUN_ARIA.cmd project create --help
RUN_ARIA.cmd project join --help
RUN_ARIA.cmd coordinator --help
```

Создание private-репозитория, установка GitHub App и изменение branch protection
являются внешними действиями и выполняются только после явного подтверждения.

## Целевая схема

Один GitHub-репозиторий проекта содержит ветки:

```text
main
dev
work/<github-username>
aria-control
```

Папка `<project>-aria-control` на ПК является worktree ветки `aria-control` того
же репозитория. Coordinator работает локально на ПК владельца. При его остановке
запросы остаются в GitHub Issue-очереди и после запуска обрабатываются
идемпотентно, без потери и повторного применения.

## Повторная установка и удаление

- `INSTALL.cmd` повторно проверяет и восстанавливает точную версию.
- `INSTALL.cmd -Recreate` пересоздаёт runtime, сохраняя `.aria-data`.
- `UNINSTALL.cmd` удаляет runtime, но сохраняет данные.
- `UNINSTALL.cmd -RemoveCodexSkill` удаляет установленный этой поставкой skill.
- `UNINSTALL.cmd -RemoveData` дополнительно удаляет локальные данные поставки.

Удалённые GitHub-репозитории эти команды не удаляют.
