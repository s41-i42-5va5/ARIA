# Установка ARIA 1.5.5 for Claude Code

## Что входит

Папка содержит полную ARIA 1.5.5, Python 3.12.10, MinGit, offline wheel-зависимости,
framework, установщик, uninstaller, документацию и SHA-256 manifest. MCP-сервера нет.

Claude Code и Anthropic credentials не распространяются вместе с ARIA. На Windows заранее
установите Claude Code и поддерживаемый Git Bash либо используйте WSL, затем выполните вход в
Claude Code обычным способом.

## Чистая установка

1. Скопируйте всю папку `1.5.5 for Claude` на Windows 10/11 x64 ПК.
2. Запустите `CHECK_RELEASE.cmd`. Ожидается JSON с `"ok": true`.
3. Запустите `INSTALL.cmd`.
4. Закройте и снова откройте Claude Code, чтобы skill и hook гарантированно перечитались.
5. Выполните `RUN_ARIA.cmd claude status`. Поля `ok`, `matches_release`,
   `hook_installed`, `hook_matches_receipt` должны быть `true`; `mcp_server` — `false`.

Установка создаёт приватные `.aria-runtime` и `.aria-data` только внутри этой папки. Skill
устанавливается в `%USERPROFILE%\.claude\skills\aria-project\SKILL.md`, а hook безопасно
добавляется в `%USERPROFILE%\.claude\settings.json`. Если задан абсолютный
`CLAUDE_CONFIG_DIR`, используется он. Чужие настройки и hooks сохраняются.

Если в Claude уже есть отличающаяся ARIA integration, установщик остановится. Только после
проверки используйте:

```powershell
INSTALL.cmd -ReplaceClaudeIntegration
```

## Публичный GitHub App профиль

Client ID и App integration ID не являются секретами. Их можно сразу записать в локальный
ARIA-профиль:

```powershell
INSTALL.cmd -GithubClientId Iv1.EXAMPLE -CoordinatorIntegrationId 123456
```

Оба параметра обязательны вместе. GitHub token и private key этим способом не передаются.
Device login выполняется отдельно через `RUN_ARIA.cmd github-auth ...`; токен сохраняется в
Windows Credential Manager. Private key Coordinator App вводится только на ПК владельца и не
копируется разработчикам.

## Работа с Claude Code

Попросите Claude обычным языком показать backlog, свободные задачи, ваши задачи, добавить идею,
взять задачу или обновить этап. Skill переводит запросы в команды ARIA. Канонические control-
файлы изменяет только Coordinator.

Канонические ветки одного GitHub repository:

- `main`;
- `dev`;
- `work/<github-username>`;
- `aria-control`.

Папка `<project>-aria-control` является локальным worktree той же ветки и того же repository,
а не отдельным remote.

## Удаление

`UNINSTALL.cmd` удаляет приватный runtime, Claude skill и ARIA hook, сохраняя пользовательские
данные `.aria-data` и GitHub provider profile. `UNINSTALL.cmd -RemoveData` удаляет также данные.
Если пользователь изменил ARIA skill, удаление остановится; после проверки используйте
`-ForceClaudeIntegrationRemoval`. Чтобы оставить skill и hook, используйте
`-KeepClaudeIntegration`.

## Внешняя приёмка

Для настоящего теста на трёх машинах нужны три отдельных GitHub-аккаунта, Claude Code на каждой
машине, изолированный private test repository и подтверждение владельца перед созданием repo,
установкой App или изменением branch protection. Локальные synthetic tests не заменяют этот gate.
