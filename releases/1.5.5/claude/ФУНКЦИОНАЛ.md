# Функциональность ARIA 1.5.5 for Claude Code

Сборка содержит полное ядро ARIA 1.5.5 из последнего P0 backlog и отдельную интеграцию Claude
Code без MCP.

## Совместная разработка

- один GitHub repository с `main`, `dev`, `work/<github-username>`, `aria-control`;
- безопасное создание, подключение и join проекта без перезаписи существующего кода;
- owner/developer роли, GitHub invitations и immutable user identity;
- идеи с подтверждённым автором, owner triage, assignee, priority, requirements, acceptance,
  dependencies и file scope;
- leases и блокировка пересекающихся задач;
- progress/activity, PR в `dev`, App-pinned checks и Coordinator-only completion;
- локальный Coordinator на ПК владельца без постоянного сервера и обязательных Actions;
- GitHub Issue queue, offline outbox, `pending_sync`, catch-up, idempotency и replay protection;
- recoverable backlog/activity/state/history transactions и безопасное восстановление сбоев.

## Claude Code

- user skill `%USERPROFILE%\.claude\skills\aria-project\SKILL.md`;
- команды `aria claude install`, `status`, `remove`;
- безопасное объединение с существующим `settings.json`;
- fail-closed `PreToolUse` hook для прямых Write/Edit/NotebookEdit в control-файлы;
- блокировка прямых shell mutations ветки `aria-control` и control-документов;
- сохранение чужих settings/hooks при установке и удалении;
- SHA-256 read-back и явная обработка drift;
- отсутствие MCP server и отсутствие Anthropic/GitHub secrets в поставке.

Hook является дополнительной защитой, но не OS sandbox. Авторитетные границы обеспечивают
GitHub permissions/protection, Coordinator App, signed/hash-bound state и Coordinator-only writes.

## Не заявлено как завершённое

- живой Claude CLI smoke на этой машине: Claude CLI не установлен;
- реальный multi-account GitHub E2E;
- установка App или изменение настроек GitHub repository;
- проверка на физически другом ПК/чистой VM.
