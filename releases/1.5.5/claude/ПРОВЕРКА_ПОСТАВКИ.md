## Ручная проверка на другом ПК

1. Скопировать всю папку.
2. Выполнить `CHECK_RELEASE.cmd`.
3. Выполнить `INSTALL.cmd`.
4. Проверить `RUN_ARIA.cmd claude status` и `RUN_ARIA.cmd doctor`.
5. Перезапустить Claude Code и попросить показать ARIA projects/backlog.
6. Проверить обычную правку исходника — она разрешена.
7. Попросить напрямую изменить `STATE.yaml` — hook должен запретить операцию.
8. Выполнить `UNINSTALL.cmd`; убедиться, что чужие Claude settings/hooks сохранены.

## Открытые внешние gates

Live Claude test требует установленного и авторизованного Claude Code. Multi-user GitHub acceptance
требует отдельных аккаунтов owner/developer-1/developer-2 и предварительного разрешения владельца
на private test repositories, GitHub App installation и repository settings. До этих проверок
поставка имеет статус local test candidate, а не финальный production release.
